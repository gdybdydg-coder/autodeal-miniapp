# План відмови від платних запитів AUTO.RIA

Зафіксовано 30.09.2026 о 23:20 Europe/Kyiv на прохання користувача «Ок, запамʼятай цей план». Це дорожня карта, а не завершена реалізація чи команда негайно змінити робочу оцінку.

Мета: пошук, перевірка оголошень і оцінювання без купівлі API-запитів. Render і PostgreSQL залишаються окремими витратами.

1. Перевірити дозволені публічні джерела, robots та умови використання. Виміряти пропуски поточного двосторінкового збирача. Без обходу CAPTCHA, cookies, прихованих endpoints або ротації IP.
2. Доробити один спільний збирач нових публікацій для всіх підписників: дата додавання, baseline, bounded queue, restart-safe дедуплікація. Установити причини переповнення та усунути їх у межах дозволеного бюджету HTTP.
3. Дослідити заміну API деталей дозволеними публічними сторінками: актуальна додатна ціна, характеристики, категорія, активний статус. Одні деталі на всі підписки. Недостатні обовʼязкові дані — очікування перевірки; відсутні необовʼязкові поля та пошкодження не блокують авто, відомі суперечності фільтрам блокують.
4. Підготувати власний приблизний ціновий орієнтир на основі порівнянних оголошень із нового потоку: модель, рік, двигун, коробка, пробіг; аномалії та дублікати відсіювати. Достатність вибірки, невизначеність і якість перевірити до доставки. Це НЕ офіційна AI-оцінка AUTO.RIA.
5. Запропонований паралельний тест 7–14 днів без додаткових сповіщень: пропуски, затримка, фільтри, оцінка, навантаження. До переходу погодити вимірювані критерії якості. Не обіцяти повного охоплення на основі часткових збігів.
6. Поетапно замінити платний пошук, потім деталі, останньою AI-оцінку. Перевірити всі робочі API-шляхи, включаючи довідники, оновлення ціни, клієнтські запуски та діагностику: кінцевий режим не робить платних викликів і не має прихованого платного fallback. Тестувати /stop, epochs, sent/uncertain claims, кеші та перезапуски; облік не скидати.

Окремий перехід на власну оцінку затвердити після демонстрації результатів: користувач погодив збереження плану, а не негайну заміну чинної paid AI / confirmed_deals_only політики. До перемикання робочий бот використовує офіційну AI оцінку, нижня межа × 0.95; формулу клієнтам не показувати. Не відновлювати старий каталог чи зупинені підписки, не повторювати попередні recovery.
