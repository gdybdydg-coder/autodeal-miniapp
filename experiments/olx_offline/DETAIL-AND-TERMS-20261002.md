У цій відповіді спостерігається JSON-LD @type=Vehicle з SKU, model,
productionDate, brand та offers. Видимі DOM ad-price-container,
ad-parameters-container, ad-posted-at містять ціну й характеристики.
Видима ціна 5750USD, JSON-LD258685UAH. Не прирівнюємо ці значення без курсу.
Верхній пошуковий JSON-LD раніше містив інші округлення; це теж не подія зміни ціни.

Новий detail_snapshot.py:
- ID та URL беруться з одного спостереженого Vehicle; неоднозначна схема зупиняє імпорт.
- Ціна — з видимого блоку, а структуроване значення зберігається поруч із валютою.
  При відсутній видимій ціні немає прихованого fallback. Same-currency conflict
  позначається явно; ціна все одно не отримує статусу full.
- Марка, модель та рік читаються з явних структурованих полів; покоління невідоме.
- Пробіг 192000 км, двигун 1400 см³, пальнеpetrol, коробкаmanual, кузовhatchback
  розібрані з конкретних підписів. Повторні суперечливі параметри стають unknown.
- VIN, номерний знак, продавець, контакти та опис не експортуються.
- Із JSON-LD отримано 5 URL фото. На видимій сторінці більше фото-елементів;
  адаптер не заявляє повного комплекту і не завантажує жодного зображення.
- «Опубліковано сьогодні…» зберігається як підпис, не доведений timestamp.
- Підтвердженої вигідності 0: ціна/клас автомобіля ще не валідовані як придатні
  для рекомендації, порівняльної вибірки немає. publication_verified=false,
  ready_for_delivery=false. Регулярного HTTP-клієнта і production wiring немає.

## Докази та перевірки

evidence/direct-detail-and-terms-20261002.json містить timestamps, HTTP-метадані,
hash префікса body, allowlisted факти та результат оцінки. Сирий HTML не у git.
Дані одного реального оголошення не доводять стабільності схеми всіх моделей,
локалей, категорій, продавців або повноти. Контрольна вибірка вигідності 0.

74/74 тестів, із них 8 нових. Перевірено валютні розбіжності, відсутню ціну,
конфлікт характеристик, неповний body, неекспортування приватних полів,
відмову при відсутній Vehicle-схемі. Окремо виконано адаптер на справжньому HTML.

```sh
python -m unittest discover -s experiments/olx_offline -v
python -m experiments.olx_offline.detail_snapshot --input /path/to/authorized-detail.html --fetched-at 1790968276 --truncated
```

етап 5 заблокований відсутністю достатніх дозволених порівнянь і незалежних міток.

перевірити деталі кількох типів, хронологічну пагінацію та первинні дати.

повідомлень 0. Нових платних ресурсів/квот 0. Фонові процеси не запускались.
