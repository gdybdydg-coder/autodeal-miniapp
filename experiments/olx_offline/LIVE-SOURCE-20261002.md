Присутність у категорії легкових не доводить класифікацію кожної картки.

Новий html_snapshot.py читає локальний HTML, без HTTP/Telegram/production imports.
Числовий ID бере з фактичного id картки, URL — з card-title-link, ціну — з ad-price;
характеристики — з окремих span. Параметри URL прибираються. Lazy placeholders не
називаються фото; JSON-LD фото додаються лише до картки з тим самим URL.
JSON-LD priceValidUntil не прирівнюється до publication time. Фото не завантажували.
Назви пального/коробки явно нормалізуються. Повна сумісність довідників із backend
ще потребує стенда; зокрема tiptronic/cvt не прирівнюються мовчки до arbitrary ID.

Адаптер зберігає observed_location_date як підпис джерела, але не вигадує timestamp
зі слова «сьогодні». Невідомі brand/generation/body не виводяться з назви.
Статуси research_only, collection_complete=false, ready_for_delivery=false явні.

## Перевірки й відтворення

66/66 тестів, із них8 нових: розбір спостережених DOM-ознак, часткова відповідь,
неповний JSON-LD, зіставлення фото, повтори ID, валюта, збережені реальні факти,
сторонній URL. Не стверджуємо, що synthetic regression є live coverage.
Реальний parser виконаний на тих самих2097152 байтах; агрегати й hash збережені:
evidence/direct-html-probe-20261002.json. Повний HTML/конфігурації сайту не публікуємо.
Сирий body був тимчасовим локальним артефактом; відтворити той самий live snapshot
після його втрати неможливо лише за hash. Два санітизовані приклади збережені в git.

```sh
python -m unittest discover -s experiments/olx_offline -v
python -m experiments.olx_offline.html_snapshot --input /path/to/authorized-snapshot.html --fetched-at 1790967379 --truncated
```

Поточний parser працює зі спостереженою українською версією. Зміна DOM/мови,
конфліктні дублікати, перевірка мінімальної повноти полів, детальна сторінка й
source-specific retry/controller ще потребують доопрацювання на даних.
Порожній результат не підтверджує відсутність оголошень.
