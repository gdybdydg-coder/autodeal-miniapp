# Нічне продовження 05.10.2026, 02:00 — EUR та доказ курсу

## Гіпотеза й фактичний результат

Для двох збережених реальних OLX-оголошень у EUR потрібна окрема перевірена пара EUR/USD. До мережевого звернення опубліковано exact URL, ліміт 1 GET / 256 KiB і цільові ID у `examples/night0200-fx-plan.json`. Ціну авто не використовували для вибору джерела або методу.

Офіційний all-currency endpoint НБУ на дату 05.10.2026 повернув HTTP 403: 1 GET, 55 bytes, retries 0. НБУ додано до persistent source hold для цієї ночі; fallback і повторних валютних звернень не було. Сире тіло відповіді приватне. Санітизований receipt: `examples/night0200-fx-evidence.json`.

Тому жодне реальне число курсу не вигадано і два EUR-випадки не перераховано. Вони мають чітку причину `eur_fx_missing`; 932274776 залишається придатним за предметом продажу, 931454683 залишається окремо виключеним перевіркою предмета. Валютна підтримка не обходить eligibility.

## Код і тести

- Додано строгий parser одного офіційного NBU response з рівно однією парою USD та EUR, цифровими кодами 840/978 і однаковою explicit датою.
- EUR→USD обчислюється тільки як крос-курс двох офіційних значень UAH на одну дату: `EUR_UAH / USD_UAH`. USD-only quote не може обслуговувати EUR.
- Quote payload зберігає `eur_rate`, окремі units, source, effective/fetched dates і basis. Невірна/відсутня/дубльована пара, інша дата, NaN або невідповідне джерело утримують конвертацію.
- Додано окремий durable cache-row `select_eur_pair`: один injected GET, 5-хвилинний cooldown, без автоматичного переходу до непідтвердженого крос-курсу. Production transport відсутній.
- На двох збережених реальних EUR-прикладах synthetic documented pair перевіряє лише математику й незмінність eligibility; це не оголошується актуальним реальним курсом.
- HTML тепер пояснює `Немає перевіреної пари курсів EUR/USD`, показує очікування валютної пари й маркує фактичну майбутню конвертацію як приблизну. Під час цієї зміни зовнішня JS-перевірка виявила синтаксичну помилку в новому рядку; її виправлено й додано постійний `node --check` regression.

Перевірка: 398 tests + 150 subtests passed; мережа/DNS заблоковані до імпорту тестів. HTML містить 62 cases, embedded JSON розбирається, JavaScript syntax valid. Browser render/скриншот усе ще не підтверджено.

Ринкові оцінки залишаються 0/62, максимум 4 сумісні аналоги при мінімумі 8. Локальне відтворення: 106 карток для двох FAKE paid, 0 unpaid, повтор 0, Telegram 0. Немає MAE/MAPE, sale-price accuracy або FP/FN.

Production/main, Render deployment, AUTO.RIA, платежі, /stop, адміністративні заявки й нічні 3600 секунд не змінювалися. Етапи 9–10 не запускалися.

Наступний запуск не має повторювати NBU або той самий широкий OLX-збір. Потрібна нова обґрунтована гіпотеза для повнішої сумісної групи або офлайн-поліпшення джерела/оцінки.
